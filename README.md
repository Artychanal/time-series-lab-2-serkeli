# Лабораторна робота №2

Аналіз місячної кількості відгуків Cyberpunk 2077 у Steam за період від грудня 2020 року до серпня 2026 року.

## Що виконує програма

- перевіряє повноту та цілісність вхідних даних;
- виявляє аномалії Hampel-фільтром;
- підбирає поріг детектора за F1;
- перевіряє очищення на контрольованих аномаліях;
- відновлює пошкоджені значення PCHIP-інтерполяцією;
- навчає поліноми першого, другого та третього степенів методом найменших квадратів;
- навчає нелінійну подієву модель;
- порівнює моделі за expanding-window validation і backtest;
- будує прогноз на 35 місяців із 95% bootstrap-інтервалами.

## Встановлення

Потрібен Python 3.12 або новіший.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
```

## Запуск

```powershell
python main.py
```

Основні показники виводяться в консоль. Файли з результатами зберігаються в каталозі `results`.

## Результати

- `analysis_summary.json` — підсумкові параметри й метрики;
- `model_comparison.csv` — порівняння моделей;
- `backtest_last_12_months.csv` — перевірка на останніх 12 місяцях;
- `forecast_35_months.csv` — прогноз;
- `anomaly_detection.csv` — результати пошуку аномалій;
- `anomaly_threshold_sensitivity.csv` — оцінювання порогів детектора;
- `injected_anomaly_validation.csv` — перевірка на контрольованих аномаліях;
- `cleaned_monthly_reviews.csv` — ряд після обробки;
- `figures` — графіки.

## Структура проєкту

- `main.py` — точка входу;
- `analysis.py` — послідовність обчислень і збереження результатів;
- `data_loader.py` — завантаження та перевірка CSV;
- `anomaly_detection.py` — Hampel-фільтр і PCHIP-очищення;
- `polynomial_lsm.py` — поліноміальні моделі;
- `nonlinear_model.py` — нелінійна подієва модель;
- `forecasting.py` — прогноз і довірчі інтервали;
- `visualization.py` — побудова графіків;
- `steam_parser.py` — оновлення даних Steam за потреби.

Основний запуск використовує файл `data/cyberpunk_2077_monthly_reviews.csv`. Парсер Steam автоматично не запускається.
